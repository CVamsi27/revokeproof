# Revokeproof integration trial

Choose a non-production change in an independently maintained repository. The trial task is to keep one original-WebSocket revocation test in an existing Playwright suite.

Use the [installed Playwright example](../README.md#try-the-installed-github-package). Subject and control must exercise the same protected resource and event path. Prove the original connection receives the baseline canary, revoke access, then verify sampled HTTP denial and a live unaffected control. Compare with a plain Playwright test for the same behavior.

Record the pinned version and runtime, cold download time, hands-on setup and assistance, machine runtime, and the concrete result or action. Compare equivalent checks on the same fixture. Record whether the check enters the normal workflow and whether it runs on a later relevant change. Record observations at 14, 30 and 90 days. A period without a relevant change remains unobserved.

The [opt-in issue form](https://github.com/CVamsi27/revokeproof/issues/new?template=integration-trial.yml) accepts sanitized summaries and synthetic reproductions. Share private repository details only with consent. The [portfolio trial record](https://github.com/CVamsi27/developer-pain-lab/blob/HEAD/docs/adoption-trials.md) tracks the current cohort and aggregates results.
